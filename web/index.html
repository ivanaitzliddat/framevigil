Help and setup guide

Connect a camera or HDMI capture card to the server computer. FrameVigil lists new inputs for setup and marks configured inputs when they disconnect. Rename a source, choose a scan interval, and add keywords or detailed conditions. Click an alert to inspect the detected text and its location in the captured frame, then acknowledge it to suppress that source and matching OCR sentence for the configured time.

Sources continue scanning when this browser closes. Browser camera capture and sound need this page to remain open. Stop all sources pauses server monitoring while keeping the page available. Shut down FrameVigil stops the Python service and requires a restart on the host computer. Alert images stay in server memory for up to one hour and disappear after a restart.
